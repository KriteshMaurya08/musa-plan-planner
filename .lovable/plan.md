# MUSA CodeX frontend prototype

## Build
- Create a restrained charcoal, white, slate, and signal-green design system with technical grid details, thin borders, compact typography, and responsive desktop/tablet layouts.
- Add shared application navigation and reusable analytical UI for metrics, scholarship data, plans, explanations, and status states.
- Keep scholarships, relationships, profile defaults, and generated plans in separate mock-data modules so APIs can replace them later.

## Connected experience
- Build a premium home page with the requested positioning, CTAs, workflow, capability summary, and a real compatibility-network preview.
- Build the student profile form with realistic controls, inline validation, and a short analysis loading transition into the dashboard.
- Build the main command center with searchable/filterable scholarship landscape, interactive graph nodes and edges, connection explanations, and scholarship detail panels.
- Build dedicated scholarship, compatibility, plans, plan-detail, what-if, and documents views, all connected through the shared navigation.
- Add plan sorting/comparison, expandable rule explanations, invalid-combination examples, responsive states, and factual demo-data labels.

## Technical approach
- Use TanStack routes, React local state, Tailwind v4 semantic tokens, and reusable components.
- Use React Flow for zoomable/pannable analytical graph behavior if compatible with the existing project; otherwise implement equivalent accessible interaction without a static illustration.
- Give every content route unique metadata and verify the main journey at desktop and tablet sizes.
